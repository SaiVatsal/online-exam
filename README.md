# PROCTORIS // Online Examination & Anti-Cheat Authority

A proctored online examination system built with React, Vite, Tailwind CSS, and Zustand, modeled on a Supabase/PostgreSQL schema with client focus-loss telemetry.

## 🎓 Key Features
- **Anti-Cheat Focus-Loss Telemetry**: Real-time browser tab-switch and blur detection logged directly to an exam audit log.
- **Clock-Forward Single-Column Exam Hall**: Distraction-free test environment with countdown timer and automated submit on zero.
- **Diverse Question Types**: Multiple choice questions (MCQ), live algorithmic code sandboxes, and long-form essay response areas.
- **Instant Objective Auto-Grading**: Immediate score calculation and percentile breakdown on exam submission.
- **Faculty Question-Bank & Review Console**: Instructor studio for reviewing essay answers, assigning manual scores, and publishing new questions.

## 🚀 Quickstart
```bash
npm install
npm run dev
```
